STUDYBOX WEBSITE — QUICK SETUP

1. Open index.html in a browser to preview the website.
2. To enable WhatsApp enquiries, open index.html in VS Code.
3. Search for: const WHATSAPP_NUMBER = "923XXXXXXXXX";
4. Replace it with your WhatsApp number including Pakistan country code, without +, spaces or dashes.
   Example format: 923001234567
5. Save and refresh the website.

The website currently uses sample product categories and displays “Ask for price”.
Edit the product names/descriptions in index.html and add your actual prices when ready.

To publish it free, you can use GitHub Pages or Netlify. Keep index.html at the root of the published folder.

6. Product photos are stored in the images folder. Keep the images folder beside index.html when publishing. You can replace these sample photos with your own product photos using the same filenames.
